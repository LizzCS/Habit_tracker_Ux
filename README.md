# Proyecto : Habit Tracker
`Experiencia de Usuario`

## Descripción
El objetivo del proyecto es desarrollar una aplicación web denominada Habit Tracker, diseñada
para ayudar a los usuarios a crear, administrar y dar seguimiento a sus hábitos y metas
personales.

---

## Tecnologías Utilizadas

- **Base de datos:** MondoDB 
- **Lenguage de Programacion:** JavaScript
- **Frontend:** Web
